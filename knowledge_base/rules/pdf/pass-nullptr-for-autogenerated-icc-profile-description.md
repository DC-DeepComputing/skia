**Rule.** When serializing ICC profiles with SkWriteICCProfile (or related
profile export functions) and requesting an auto-generated unique description
tag, pass nullptr as the description argument instead of an empty string ("").

**Why.** SkWriteICCProfile treats both nullptr and empty strings ("") as
requests to auto-generate an MD5-based description tag. Passing nullptr clearly
communicates caller intent to rely on auto-generation rather than supplying an
empty or dummy description.

## Examples

Bad:

```cpp
sk_sp<SkData> iccData = SkWriteICCProfile(&iccProfile, "");
```

Good:

```cpp
sk_sp<SkData> iccData = SkWriteICCProfile(&iccProfile, nullptr);
```
